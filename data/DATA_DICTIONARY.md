# Data Dictionary

All data is **synthetic**. It was generated by `scripts/generate_synthetic_data.py` (seed 42) and does not represent real people or organizations.

## members.csv
| Column | Description |
|---|---|
| member_id | Unique member key |
| date_of_birth | Date of birth |
| sex | F / M |
| payer | Medicaid, Medicare, or Commercial |
| region | County of residence |

## enrollment.csv
| Column | Description |
|---|---|
| member_id | Member key |
| payer | Payer for this span |
| start_date / end_date | Coverage span. About 8% of members have a gap, to test continuous-enrollment logic |

## providers.csv
| Column | Description |
|---|---|
| provider_id | Unique provider key |
| provider_name | Fictional name |
| provider_type | Psychiatrist, Psychiatric NP, Psychologist, LCSW, LPC, or Primary Care Physician |
| is_behavioral_health | Y if visits with this provider count toward the measure |
| region | Practice location |

## inpatient_stays.csv
| Column | Description |
|---|---|
| encounter_id | Unique inpatient encounter key |
| member_id | Member key |
| facility_id / facility_name | Discharging facility (fictional) |
| admit_date / discharge_date | Stay dates |
| principal_dx_code / principal_dx_desc | ICD-10-CM principal diagnosis |
| dx_category | Diagnosis grouping used in the dashboard |
| discharge_disposition | Where the patient went at discharge |
| followup_appt_scheduled_at_discharge | Y if an aftercare appointment was booked before discharge |

## outpatient_visits.csv
| Column | Description |
|---|---|
| visit_id | Unique visit key |
| member_id | Member key |
| visit_date | Date of service |
| provider_id | Rendering provider |
| visit_setting | Office, telehealth, CMHC, IOP, or PHP |
| primary_dx_code | Primary diagnosis on the visit |

## fuh_measure_output.csv
This is the output of `vw_fuh_measure`: one row per eligible index discharge. It includes the `fuh_7_day` and `fuh_30_day` flags (1 = compliant), `days_to_followup`, `length_of_stay`, and `age_group`. You can load it straight into Power BI if you're not using SQL Server.
